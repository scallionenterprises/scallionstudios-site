<h3>Construction</h3>

<div class="product-images">
    {% include product-image.html file="plan.jpg" %}
</div>

<p>The idea was to have a dog-crate bed that doubled as a side table. Originally the idea was to have a grid of windows in the sides, however that transitioned to circular openings for manufacturing reasons.</p>

<p>The biggest unknown in the project was the feasibility of the curved corners using plywood, so I created a test piece first.</p>

<div class="product-images">
    {% include product-image.html file="feasibility.jpg" %}
</div>

<p>A 90 degree bend can be achieved by kerf cutting, which is where multiple cuts mostly-through plywood (but not all the way through) are made close together, allowing space to bend the plywood. Then, hot water is poured all over to soften up the wood and then the plywood is clamped into a 90 degree shape. I created some 90 degree bend wood scrap pieces to clamp to.</p>

    {% include product-image.html file="in_progress_half.jpg" %}

<p>Circular openings are much easier to precisely cut since you only need to set the center of a hole saw. A grid of rectangular shapes has many more points of failure in alignment.</p>
